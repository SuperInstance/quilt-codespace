# quilt-codespace — Knowledge Map

The index of indexes for this repo. Every deeper artifact routes from here.

## In this repo

- `scripts/quilt-http-server.js` — the HTTP+SSE cell API; args `--port/--token/--state`;
  engine = `@quilt/core` import or `SimpleEngine` fallback; seed state at
  `~/.quilt/state/seed.json` with demo cells (`demo.greeting`, `demo.visitor_count`,
  `meta.*`).
- `.devcontainer/devcontainer.json` — universal image, node 22 / python 3.12 /
  docker-in-docker features, ports 7681/4096/8080 (labeled TUI / HTTP API / Dashboard),
  `QUILT_TIER=codespace`, `QUILT_INSTANCE_ID=codespace-default`.
- `.devcontainer/post-create.sh` — the boot: quilt npm packages, token generation
  (`~/.quilt-env`), state dirs, ttyd 1.7.7 install, three nohup'd services, connection
  info printout, guarded oracle setup hook.
- `.github/workflows/ci.yml` — push/PR smoke: YAML-parse `examples/fed-autopilot/cell.yaml`
  (`|| true`), JSON-parse devcontainer.json (hard gate), HTTP smoke on :14196 with
  test-token.
- `oracle/oracle.py` — deterministic repo-oracle: `build`, `where`, `what`, `hot`,
  `touching`, `plan`, `ask`, `receipt`, `verify`, `serve [--port 4097]`; repo-map in
  `.quilt/repo-map/{tree,symbols,heat}.json`; sha256 receipt chain at
  `.quilt/oracle-receipts.jsonl`.
- `oracle/self-test.sh` — pins P0 (fail-first NO_MATCH), P1 build, P2–P5 queries,
  P6 chain verify, P7 tamper → `RECEIPT_HASH_MISMATCH`, P8 custody gap → `CUSTODY_GAP`,
  P9 serve `/health`.
- `oracle/fix-loop.sh` — the expert-coder loop: claim (TASKS.md lease row) → apply patch
  (`--apply <script>` or bundled fixture) → test → receipt; ≤3 tries; WHY line to
  ADJUSTMENTS.md on each fail; commit-as-tick on pass.
- `oracle/fixture-patch.sh` — the bundled real fixture: appends the "Oracle API (added by
  wave-66)" section to README.md if `port 4097` is absent (idempotent).
- `oracle/codespace-setup.sh` — boot evidence: `oracle-evidence/boot-<ts>.json` +
  `selftest-<ts>.log`; optional push to `oracle-evidence-<ts>` branch using the
  Codespace's `GITHUB_TOKEN` (non-fatal on denial).
- `oracle/TASKS.md` — claim board: T1 ports doc-drift fixture, T2 oracle `/ask` → http
  `/meta`, T3 quilt-in-git hook swap; 30-minute lease convention.
- `oracle/DECOMPOSITION.md` — worked T1 cell graph (c1 LOCATE → c2 EDIT → c3 TEST → c4
  RECEIPT), the four loop invariants, the two-agent sketch.
- `oracle/DECOMPOSITION-draft.md` — generated by `oracle.py plan`; amended-by-hand whys
  belong in ADJUSTMENTS.md.
- `oracle/ADJUSTMENTS.md` — the why-ledger; carries the T1 amendment (README had no ports
  table → EDIT cell became APPEND; PREFLIGHT candidate cell queued).
- `tools/repo-oracle.mjs` — portable history-oracle: 13 read-only probes, focus rules,
  trail composition, `--json`, `--save <dir>`, `self-test` (12 pins incl. read-only HEAD
  guarantee).
- `driver/oracle-worker.sh` — outside-in Codespace driver: `create [branch]`,
  `ssh <cmd>`, `delete`, `watch <repo> <ref-glob> [--interval N]` (ls-remote polling,
  diff output on dial change).
- `docs/two-agent-pipeline.md` — the iteration-pipeline design (status: design only, not
  run): A decomposes → B executes → B's diff becomes A's new evidence; files-not-broker.
- `docs/oracle-sessions/` — 4 transcripts (.md + .json each): quilt-jev-toolkit @ c9840b2
  (provenance of tip), quilt-codespace @ cdcbefa (what is this repo / who works here),
  erised-exocortex @ 661acc6 (what laws does this repo enforce), fleet-seeds @ 3dbd72e
  (where do the receipt ledgers live).
- `examples/fed-autopilot/cell.yaml` — the 3-tier federation sheet: remote.rudder_angle /
  compass / wind / obstacles subscribed from ESP32+Jetson URIs; `state.course_error`,
  `state.wind_error` formulas; `ai.anomaly_score` (kind: ai, classify via z.ai prompt);
  `ai.should_alert` formula; `tune.pid_*` pushed to ESP32; `audit.last_decision` pushed
  to the cloud tier.
- `ORACLE.md` — the PoC charter: vision, the three laws, the Codespace PoC protocol,
  proven-vs-parked.
- `README.md` — runtime docs: services table, federation model, fed-autopilot narrative,
  persistent-state caveats, tier auto-detection (`detectTier()`), cocapn room mapping,
  cross-references.
- `.gitignore` — `node_modules/`, `*.log`, `.DS_Store`, `.env`, `.env.local`, `.quilt/`.
- `assets/splash.png` — splash image asset.

grep -n "PROBES" tools/repo-oracle.mjs          # the battery definition
grep -n "chain_append\|chain_verify" oracle/oracle.py

# All receipt ops the chain knows about
grep -rn '"op"' oracle/*.sh oracle/oracle.py | grep -v '^\s*#'
python3 oracle/oracle.py verify                  # then read .quilt/oracle-receipts.jsonl

# Law statements across the repo (the oracle's own lens)
grep -rn "law\|invariant\|never" ORACLE.md oracle/DECOMPOSITION.md docs/two-agent-pipeline.md

# Federation URIs in the wild (examples)
grep -rn "quilt://" examples/ README.md

# Journal trails
grep -n "quilt-codespace" /path/to/worklog.md
