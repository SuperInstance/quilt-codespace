# DECOMPOSITION.md — worked example: T1 (ports doc drift), decomposed by the oracle for the oracle

This is the self-decomposed logic the oracle-vision asks for: **the agent
decomposed this fix for itself, from its own repo-map**, and the loop below
is executable without any external model. Draft was generated by
`oracle.py plan "fix the ports doc drift in the http server"`, then amended
by hand — every amendment's *why* is in ADJUSTMENTS.md.

## Cell graph

| cell | kind    | detail                                                    | depends on |
|------|---------|-----------------------------------------------------------|------------|
| c1   | LOCATE  | confirm scope: scripts/quilt-http-server.js (port default) | —          |
| c2   | EDIT    | apply doc fix in README.md (ports table)                   | c1         |
| c3   | TEST    | run `bash oracle/self-test.sh` (pins must stay green)      | c2         |
| c4   | RECEIPT | commit as tick; fix-loop appends task.done receipt         | c3         |

## Invariants the loop enforces

1. Every EDIT is followed by a TEST cell — no untested edits survive.
2. Every run appends receipts (`task.claim` → `fix.attempt`* → `task.done`).
3. Every failed attempt appends a WHY line to ADJUSTMENTS.md before retry —
   the adjustment is spent twice: once as effort, once as structure.
4. Rewind law: receipts are append-only; nothing is ever deleted, a failed
   run is a valid historical state.

## Two-agent pipeline sketch (parked until single loop receipts end-to-end)

Worker B watches worker A's dial state via `git ls-remote refs/quilt/*`
(kilobyte protocol, no clone), claims rows in TASKS.md that are `open` and
not under A's lease, and runs its own fix-loop. Conflicts resolve by lease
timestamps, not by merge — the board is the coordination surface.
